# Colpilot

Colpilot 是 Windows 桌面工具的统一工作台。程序会读取当前程序目录提供的插件，显示插件卡片，并负责插件的启用、停用、排序、配置保存和运行进程管理。

## 开始使用

1. 取得 Colpilot 发布文件。
2. 将 Colpilot 文件夹放到一个具有写入权限的目录。
3. 保留 colpilot.exe 和同级目录的完整结构。
4. 双击 colpilot.exe 启动程序。

程序启动后会打开工作台，并在后台启动本地服务。首次保存程序设置或插件设置时，程序会在对应目录创建配置文件。

## 更新程序

1. 在任务栏托盘菜单中退出 Colpilot。
2. 将新版 Colpilot 文件夹中的全部内容复制到原程序文件夹，选择替换同名文件。
3. 双击原程序文件夹中的 colpilot.exe 启动新版程序。

发布文件包含主程序、运行环境和插件运行文件。程序配置、插件配置和运行数据由原程序文件夹保留。

## 主界面

### 左侧导航

左侧顶部显示 Colpilot 程序名称。插件管理区域会显示当前可以使用的插件：

- 点击插件名称，右侧页面会滚动到对应插件卡片。
- 按住鼠标左键拖动插件，可以调整插件顺序。
- 拖动时，插件之间的空隙会显示当前位置。
- 调整后的顺序会保存，并应用于左侧导航和右侧卡片。

持续运行的插件会在名称右侧显示运行状态。状态颜色和具体含义以插件页面显示内容为准。

### 插件卡片

右侧仪表盘会显示所有已经加载的插件卡片。每张卡片包含插件名称、功能说明、插件页面和启用状态。

点击卡片底部的按钮可以启用或停用插件。停用插件后，插件页面会停止提供对应功能；重新启用后，插件会按照自己的运行方式恢复。

## 设置

点击左侧顶部的设置按钮可以打开内置设置窗口。

### 外观

外观页面可以选择预设主题，也可以单独调整主题色、背景色、左侧栏颜色、卡片颜色、文字颜色和边框颜色。保存后，主界面会立即使用新的颜色。

### 插件下载

插件下载页面支持输入 GitHub 仓库 URL 安装插件，也支持选择本地 ZIP 仓库文件导入私有插件。ZIP 文件需要包含一个有效的 `manifest.json`，并且只能包含一个插件目录。已安装插件会显示来源信息；GitHub 来源会按照设置的时间间隔检查仓库提交状态，默认间隔为 120 分钟，检查结果会显示“【已是最新】”或“【需要更新】”。本地 ZIP 来源显示为本地压缩包。插件安装后需要重新启动 Colpilot 才能加载。

### 关于

关于页面显示作者和当前版本。

## 插件说明

每个插件目录都包含自己的 README.md。插件专属说明包括：

- 插件功能和使用条件
- 账号、密码或其他配置要求
- 外部服务和网络要求
- 配置文件位置
- 运行文件和后台进程
- 插件专属操作与故障处理

使用或安装某个插件前，请阅读该插件目录中的 README.md。插件卡片的具体功能由插件自身决定，Colpilot 负责提供统一的显示、配置保存和进程管理。

## 配置文件

程序级配置保存在程序目录的 config.ini 中，主要记录：

- 插件启用状态
- 插件显示顺序

每个插件的配置保存在自己的目录中：

plugins\\<plugin-id>\\config.ini

插件配置文件可能包含账号、密码或其他个人信息，请保护这些文件。发布文件不会预先包含个人配置；程序在用户首次保存设置时创建对应文件。

更新设置时，程序会保存请求中实际提交的字段。密码输入框为空时的处理方式、清除账号信息的方法和其他特殊规则，按照对应插件 README.md 的说明执行。

## 关闭程序

关闭主窗口后，程序会回到任务栏托盘。需要结束 Colpilot 时，请在任务栏托盘图标上打开右键菜单并选择退出。

退出操作会依次停止插件任务、本地服务和桌面窗口。插件正在关闭外部进程时，程序会等待进程完成关闭。

## 常见问题

### 运行日志

程序目录的 `data/logs` 保存 `desktop.log`、`backend.log` 和 `python-fault.log`。日志包含程序启动与退出、插件状态变化、子进程登记、请求异常和 Python 异常。普通运行日志每个文件达到 5 MB 后轮换，桌面程序和后端分别保留 10 份历史文件。Python 故障日志在启动时检查大小，保留 3 份历史文件。

持续监控插件的原生窗口日志位于 `plugins/colmon/data/logs`。每个文件上限为 5 MB，按日期与大小轮换，最多保留 14 个文件。日志记录任务栏窗口附着、相关窗口消息、操作耗时及响应检查；窗口线程超过 5 秒没有响应时，独立检查线程会记录正在执行的操作。

开发目录的 `scripts/check-colpilot.ps1` 用于检查主程序、持续监控窗口、任务栏响应、新增 Windows 故障事件和错误日志。首次使用或完成一次异常处理后，使用 `-Initialize` 设置检查起点。每次结果保存在 `artifacts/monitoring`，发现异常时同时保存程序日志与窗口状态。

### 工作台没有显示插件

请确认插件文件位于程序目录的 plugins 文件夹中，并阅读对应插件 README.md 检查目录结构和运行条件。修改插件文件后，重新启动 Colpilot。

### 插件页面显示错误

先查看插件页面中的错误信息，再按照对应插件 README.md 检查账号、密码、网络连接、文件夹权限和外部服务状态。

### 配置无法保存

请确认程序目录和插件目录具有写入权限。Colpilot 文件夹建议放在用户拥有写入权限的目录中。配置文件被其他程序占用时，请关闭占用程序后重新保存。

### 程序退出时间较长

持续运行插件可能需要关闭后台进程和外部窗口。等待退出操作完成后，再次启动 Colpilot。
